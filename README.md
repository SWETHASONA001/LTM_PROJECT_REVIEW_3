# AeroHydro-PINN

**Multimodal physics-AI for wake-aware hydrogen optimization** — an engineering platform that combines real wind SCADA, tidal-current and electrolyzer data with physics-informed models, a wake model and FLORIS, a turbine-placement optimizer, hydrogen dispatch and an engineering copilot. Every figure is labeled by provenance: observed, processed, predicted, physics-derived, simulated or optimized.

```
data/raw/      real datasets (read-only, not committed)
scripts/       build_frontend_data.py → provenance-tagged JSON extracts
ml/            CNN-PINN, Physics-GNN, forecaster, Isolation Forest (training + inference code)
models/        trained artifacts (.pt committed; large .joblib regenerated by ml/ scripts)
frontend/      React + TypeScript + Vite (R3F digital twins, planner, copilot, analytics)
backend/       FastAPI: datasets, FLORIS, optimizer, model inference, hydrogen, copilot agent
docs/          AUDIT.md (repository, data & model audit), DEPLOYMENT.md
```

## Run locally

```powershell
.\start-local.ps1          # backend http://127.0.0.1:8000 (docs at /docs) + frontend http://localhost:5173
```

Manual equivalent:

```bash
py -3.11 scripts/build_frontend_data.py                     # data extracts (~15 s)
cd backend && py -3.11 -m venv .venv
.venv/Scripts/python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python ../ml/train_cnn_pinn.py                # ~3 min  (also: train_physics_gnn, train_forecaster, train_isolation_forest)
.venv/Scripts/python -m uvicorn app.main:app --port 8000
cd ../frontend && npm install
echo VITE_API_BASE_URL=http://localhost:8000 > .env.local && npm run dev
```

Without the backend the frontend still runs (standalone mode: static extracts + in-browser physics); backend-only features say so in the UI.

**Copilot LLM:** set `ANTHROPIC_API_KEY` in the backend's environment to switch the copilot from local tool mode to the Claude agent (`claude-opus-5-5`, tool use over the project APIs). Without it, the copilot answers with deterministic project tools and states that no LLM is connected.

## Models (held-out test: Oct 2017 → Jan 2018)

| Model | Result |
|---|---|
| CNN-PINN (physics residuals in loss) | R² 0.949, RMSE 121 kW; 9 Betz/rated violations in a 1,212-point sweep vs 485 without physics loss |
| Physics-GNN (direction-dependent adjacency) | R² 0.945; no gain over the no-message-passing ablation (reported as a finding) |
| Gradient-boosted forecaster (CQR intervals) | 6–10 % lower RMSE than persistence at 6–24 h; on par at 1 h |
| Isolation Forest | 222 multivariate events, compared with the residual detector |
| Gaussian wake model vs FLORIS 4.6 | farm power within +0.44 % on the default layout |
